# JSON 检查器与窗口 UI 验证记录

日期：2026-10-23（Asia/Shanghai）。本次在 M1 基础上按参考图改进布局和 JSON 检查能力，未 commit，仍只注册 JSON。

## 行为与边界

- macOS 原生标题栏透明，内容覆盖标题栏区域，移除白色标题条和重复的可见窗口标题。保留系统关闭、最小化、全屏按钮；侧边栏与工作台分界线延伸到窗口顶部。顶部给三色按钮留出位置，双击标题区域调用系统标题栏双击行为。
- 侧边栏只保留一行品牌名和搜索框，移除副标题及「全部 / 数据」筛选按钮；分类按可折叠文件夹显示。只显示有搜索命中的分类，搜索期间强制展开匹配分类，清除查询后恢复原折叠状态。
- 顶部 ‹ 或 ⌘B 收起整个侧边栏，「展开 ›」恢复。宽度由 210 缩至 80 逻辑像素，顶部继续给原生三色按钮留位，窄栏保留工具和搜索入口。输入、结果、选中节点、查询及文件夹状态保留，收起状态只在本次窗口内保存。隐藏已聚焦的侧边栏搜索框时转焦到原文；在命令面板中切换会先关闭面板并恢复焦点。
- 原文与结果左右分栏，中间可拖动。窗口缩小时重新约束分栏比例，避免原文或结果工具栏被挤没。默认窗口 1240 × 780，最小尺寸 860 × 560（逻辑像素）。比例只保存在本次窗口内，不写磁盘。
- 格式化默认展示 JSON 树；压缩默认展示只读文本，可随时切换视图。两者均不改原文；「复制结果」复制已存的完整运行结果。
- 对象按输入键顺序排列；数组按下标排列。初始展开根，嵌套容器默认折叠。支持单节点折叠/展开、全部展开/收起、节点选择、聚焦容器子树、返回根、复制节点 JSON 值。
- JSONPath 使用 `$["key"][0]` 形式；jq 栏使用 `.["key"][0]` 过滤表达式。键名按 JSON 字符串转义，支持点号、引号、空键、斜杠、波浪号、换行、反斜杠、中文和 emoji。聚焦子树后路径仍相对于整个文档的根。jq 栏不执行命令，也不替用户添加 shell 引号。
- 路径栏使用只读单行文本框，可横向滚动、选取复制，也有独立复制按钮。树中 ↑↓ 选择，←→ 折叠/展开或进入子节点，Enter 聚焦容器，Esc 返回根，⌘C 复制节点值。`JsonTree` 键上下文独立于编辑器和命令面板。
- 编辑输入后保留上次结果/错误，显示待更新提示；撤销回到运行时原文后提示消失。重新运行解析失败时清除旧结果和旧树，报告行列并定位原文；清空同时移除输入、结果、树和路径。
- 新增窗口级 ⌃⌘F 全屏切换、⌘M 最小化；⌘K / ⌘W 继续保留。

## 自动检查

最终构建通过以下命令。本机使用临时 registry 参数，不写 Cargo 配置，不修改 lockfile 的 crates.io source。

```sh
cargo test --config 'source.crates-io.registry="sparse+https://rsproxy.cn/index/"' --offline --workspace
cargo clippy --config 'source.crates-io.registry="sparse+https://rsproxy.cn/index/"' --offline -p devtools-core -p devtools-tools -p devtools --all-targets -- -D warnings
cargo fmt --all -- --check
cargo build --config 'source.crates-io.registry="sparse+https://rsproxy.cn/index/"' --offline -p devtools
```

共 26 个单测：壳 10、core 3、tools 13。较 M1 新增 5 个：

| 测试 | 覆盖 |
| --- | --- |
| 有序节点 | 键顺序、父子链接、绝对路径、节点取值、格式化与原函数精确一致 |
| 特殊键名 | 含点/引号/空键/换行/反斜杠的路径与 jq 转义，JSON Pointer 的 `~`、`/` 转义 |
| 根节点 | 数字、布尔、null、字符串、空对象/数组；严格拒绝空输入、尾逗号、尾随内容 |
| 树导航 | 展开、方向键选择、子树聚焦、返回根、全部展开/收起；聚焦后路径保持绝对 |
| 空容器导航 | 空容器稳定选择，根可以收起并重新展开 |

另用本机 `/opt/homebrew/bin/jq` 实际执行 5 组按同一规则生成的过滤表达式，对比取值：多层特殊键、中文/emoji、数组、标量根、形似 jq 插值的反斜杠键，均通过。jq 只用于开发验证，没有成为应用运行时依赖。

## 原生窗口检查

通过仓库外临时 `.app` 外壳运行同一构建产物，以原生自动化点击、按键、拖动及截图观察；这不是正式打包/签名。下面是实际观察到的结果：

| 场景 | 结果 |
| --- | --- |
| 视觉布局 | 原文在左、结果在右；顶部紧凑；分类文件夹；融合标题栏无白色横条，原生三色按钮仍存在于辅助功能树 |
| 中文字体 | 初次树显示曾出现错误汉字；加入与编辑器相同的显式 Menlo → PingFang SC / 系统字体回退后，节点「名字」「小明」和容器计数正常 |
| 分栏拖动 | 拖动中间分隔条后左右宽度改变，树与路径栏仍可用 |
| 小窗口 | 将窗口缩至约 860 × 560；原文操作、结果切换、树与路径栏仍可见可用 |
| 节点交互 | 鼠标展开 users；方向键进入数组元素；Enter 聚焦元素子树；Down 选中「名字」后 JSONPath/jq 仍带 users 和数组下标；Esc 返回根 |
| 特殊键路径 | 选中 `a.b → q"uote → 空键`，显示 `$["a.b"]["q\"uote"][""]`；复制 JSONPath 再粘贴到原文，内容一致 |
| jq 复制 | 选中中文键后复制 jq，再粘贴到原文，得到 `.["users"][0]["名字"]` |
| 结果待更新 | 上述替换原文后显示待更新提示，树仍来自上次运行；撤销恢复原文后提示消失 |
| 压缩与文本 | 压缩后自动显示文本视图，结果为紧凑 JSON，原文保持原样 |
| 失败与清空 | `{"a":1,}` 显示第 1 行第 8 列错误，旧树消失、复制结果不可用；清空移除错误与输入 |
| 文件夹与搜索 | 文件夹可以收起；搜索「路径」后自动展开并显示 JSON；⌘K 独立搜索 json 正常，Esc 恢复原焦点 |
| 侧栏收起/展开 | 点击顶部箭头收起后原文/结果变宽；点击展开后原文 `1`、结果根节点 `1`、JSONPath `$` 和 jq `.` 保留 |
| 隐藏搜索焦点 | 在侧边栏搜索输入 `j` 后按 ⌘B，再输入 `2`，原文从 `1` 变为 `12`，旧结果保留并提示待更新；展开后查询仍为 `j` |
| 窄栏搜索与快捷键 | 点击窄栏搜索打开命令面板；面板中 ⌘B 关闭面板并展开侧栏，查询和原文均保留 |
| 系统全屏 | 点击原生全屏按钮后进入系统全屏，布局重新适配 |
| 关闭 | 从全屏状态 ⌘W 关闭，应用可以重新启动 |

最后一轮自动化粘贴收到并发剪贴板操作提示；已读取当前窗口确认内容，并停止继续自动输入。最终构建的新增 ⌃⌘F / ⌘M、全屏退出后的三色按钮恢复，以及窗口顶部拖动尚未单独完成自动化验收。没有因该提示改动用户输入或清空正在试用的窗口。

真实系统 IME、跨行拖选、超大 JSON/大量树节点压力仍沿用 [M1 剩余人工检查](m1-validation.md#尚未完成的人工验收)。当前树逐节点构建和渲染，尚无虚拟列表或大文件性能承诺。

## 代码入口

- `crates/devtools-tools/src/json/tree.rs`：严格解析结果、有序节点、路径转义和节点取值，无 GPUI。
- `crates/devtools/src/tree_state.rs`：折叠、导航、选择与子树状态，无 GPUI。
- `crates/devtools/src/json_run.rs`：一次解析同时得到输出和检查树。
- `crates/devtools/src/json_workbench.rs`：分栏、树/文本、路径面板、复制和待更新提示。
- `crates/devtools/src/main.rs` / `workspace.rs` / `actions.rs`：原生透明标题栏、分类文件夹、侧栏收起与展开和键上下文。
- `crates/devtools/src/theme.rs`：编辑器和树共用的字体回退。
